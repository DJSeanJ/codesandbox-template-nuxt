GHL embed snippet — Life Is Gonna Life

Paste the matching block into a Custom Code element on each GHL day page. Replace CHAT_HOST with your deployed chat-widget URL.

Day 1 page

<!-- BEGIN: Life Is Gonna Life chat widget (Day 1) -->
<iframe
  id="ligl-chat"
  src="https://CHAT_HOST/embed?day=1"
  style="position:fixed;right:0;bottom:0;border:0;background:transparent;width:88px;height:88px;z-index:2147483640;transition:width 180ms ease,height 180ms ease;"
  allowtransparency="true"
  title="Talk to the artist"></iframe>
<script>
(function(){
  var f=document.getElementById('ligl-chat');
  window.addEventListener('message',function(e){
    if(!f||e.source!==f.contentWindow)return;
    var d=e.data;
    if(!d||d.source!=='lifeisgonnalife'||d.type!=='resize')return;
    var w=Math.min(d.width,window.innerWidth);
    var h=Math.min(d.height,window.innerHeight);
    f.style.width=w+'px';
    f.style.height=h+'px';
  });
})();
</script>
<!-- END: Life Is Gonna Life chat widget -->

Notes for the next person who touches this

  • For each new day you release, copy a block, change day=N, paste into that day's GHL page.
  • The chat host must allow iframe embedding from your GHL domain. The CSP frame-ancestors header is set on the /embed route in nuxt.config.ts; tighten it from * to your specific GHL domain before launch.
  • The id="ligl-chat" attribute must be unique on the page. If GHL inserts the snippet twice, the second one wins.
  • z-index 2147483640 is intentionally just below the JavaScript max so most overlays stay above it. Lower if it covers something it shouldn't.
